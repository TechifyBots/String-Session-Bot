## 🌸 Overview

**String Session Bot** is a versatile, open-source Telegram bot built to **generate Pyrogram and Telethon string sessions**, including **bot sessions** for both (User + Bot) frameworks. It provides a simple and reliable way to generate sessions directly through Telegram.

> 💡 *Simple to use, easy to deploy, and packed with essential tools for Telegram developers.*

#### 🤔 Why Choose This Project?

- ⚡ **Fast & Simple** — Generate string sessions directly through Telegram with an easy workflow.
- 🔐 **Reliable** — Supports both **Pyrogram** and **Telethon** session generation.
- 🚀 **Easy Deployment** — Deploy quickly on platforms like **Koyeb, Heroku, and Railway**.
- 🛠️ **Developer Friendly** — Includes useful management tools and a clean, customizable structure.

#### 🔄 How It Works

1. 📱 **Start the Bot** — Open the bot and start the session generation process.
2. ⚙️ **Choose Session Type** — Select the required **Pyrogram or Telethon** session.
3. 🔑 **Generate Session** — Provide the required Telegram credentials and generate your session.
4. ✅ **Use Your Session** — Copy the generated string and use it in your Telegram projects.

---

## ✨ Features

- 🤖 **Pyrogram Session** — Generate Pyrogram user string sessions.
- 🤖 **Pyrogram Bot Session** — Generate string sessions for Pyrogram bots.
- 📱 **Telethon Session** — Generate Telethon user string sessions.
- 🤖 **Telethon Bot Session** — Generate string sessions for Telethon bots.
- 🔐 **Multi Force Subscribe** — Add multiple public & private channels for force subscription.
- 📢 **Broadcast System** — Send messages to all registered bot users.
- 🛠️ **Maintenance Mode** — Temporarily disable bot services when required.
- 🚫 **Ban & Unban** — Manage restricted users easily.
- 🚀 **Multi-Platform Deployment** — Deploy on **Koyeb, Heroku, Railway & more**.
- 💬 **24/7 Developer Support** — Get help whenever you need it.

## 📝 Configuration


| Variable | Description |
|:---------|:------------|
| `API_ID` | Telegram API ID |
| `API_HASH` | Telegram API Hash |
| `BOT_TOKEN` | Telegram Bot Token |
| `DB_URI` | MongoDB URI |
| `ADMIN` | Telegram User ID |
| `PICS` | Start Images |
| `IS_FSUB` | Enable / Disable Force Subscribe |
| `FSUB_EXPIRE` | Force Subscribe Expire Time |
| `AUTH_CHANNELS` | Force Subscribe Channels |
| `AUTH_REQ_CHANNELS` | Request FSUB Channels |
| `LOG_CHANNEL` | Log Channel |

## 🤖 Commands

```
start - Check Bot Alive.
stats - Check bot stats.
gen - To start generation string session.
cancel - To cancel the string generation process.
ban - to ban a user.
unban - to unban a user.
banned - to check banned users.
maintenance - Toggle maintenance mode
broadcast - Broadcast messages to all bot users.
```
